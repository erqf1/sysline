How it works

Three steps, then just play.

Sysline sits in the tray. It keeps out of the way until you need it.

01

Pick your values

Choose what the overlay shows, which corner it sits in, how big it is and how see-through.

02

Set up your keys

Remap keys, switch off the Windows key or record a macro. Every game can get its own profile.

03

Start your game

Sysline sees which game is in front and switches to its profile. Ctrl+Shift+O shows or hides the overlay.

Real frame rate

On Windows, Sysline counts frames the way PresentMon does. Without admin rights it says so instead of guessing, and one click allows it for good.

One key

Remap any key

One key becomes another or a whole combination like Ctrl+Shift+S. Switch keys off you keep hitting by accident, like the Windows key.

Macros with pauses

Record a sequence or type it line by line. Play it once, several times or for as long as you hold the key. Off by default, because some online games ban them.

A profile for every game

Sysline sees which program is in front and switches keys and macros by itself. Everything else uses the standard profile.

No driver, no account

Sysline installs no kernel driver and sends nothing anywhere. That is also why it leaves out the CPU temperature on Windows instead of making it up.

FAQ

Questions

Is it really free?

Yes. Sysline is open source under the Apache 2.0 license, with no account and no ads. The only thing that goes online is the ping you set and the check for a new version.

Why does the frame rate say “admin rights needed”?

Windows only lets programs with admin rights or members of the group “Performance Log Users” count frames of other programs. Start Sysline as administrator, or click “Allow without admin rights” once and sign out and in again.

Why is there no CPU temperature on Windows?

Windows only gives it to programs with their own kernel driver. Sysline doesn't install one, so it leaves the value out instead of showing a wrong number. On Linux it comes from the kernel's own sensors.

Can I get banned for using it?

The overlay only reads system values and draws a window on top. Macros are a different matter: many online games forbid them and anti-cheat software can detect them. That's why macros are off until you switch them on, and why you should only use them where the game allows it.

I don't see the overlay in my game.

Games in exclusive fullscreen draw over every other window. Switch the game to borderless window or windowed mode and the overlay appears.

A remapped key does nothing in one game.

If the game runs as administrator, Windows only lets it receive keys from programs that run as administrator too. Start Sysline the same way.

Which languages does the app speak?

German and English. It follows your system language and can be changed in the settings.
